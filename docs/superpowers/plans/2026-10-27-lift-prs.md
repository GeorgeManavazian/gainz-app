# Lift PRs and Progression Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show the all-time best set in the set sheet, badge sets that beat it, and pre-fill the weight wheel from George's 5–9 rep double-progression rule.

**Architecture:** One new pure module `lib/progression.ts` (best-by-weight, PR test, typical jump, suggestion) with vitest coverage; the workout page computes `best` + `suggestion` per open exercise and passes them to `SetSheet`, which renders a second header line, a chip, and PR pills; `WorkoutSummary` renders the same pills; Performance's "Best set" card switches to the shared definition.

**Tech Stack:** Next.js App Router client components, TypeScript, Tailwind token classes, vitest (node env).

**Spec:** `docs/superpowers/specs/2026-10-27-lift-prs-design.md`

## Global Constraints

- No hex colours outside `app/globals.css`; use token classes (`text-accent`, `bg-accent/15`, `text-muted`, `border-border`, `bg-surface-2`).
- Weight wheel values are `range(0, 500, 2.5)` (`WEIGHT` in `components/SetSheet.tsx`); every suggested weight must land on a 2.5 multiple.
- `normalizeName` from `lib/exercises.ts` for every exercise-name comparison.
- Best = highest weight, ties by highest reps, then earliest `logged_at`. Never e1RM.
- Chip copy exact: `Try {w} · hit {r} last time` / `Stay {w} · aim 8+` / `Stay {w} · build to 5`. Header line exact: `Best: {w}×{r} · {shortDate}`.
- No schema, no new routes, no new dependencies.
- Commit per task; `npm test` green before each commit.

## Review Focus

1. A session whose top set has `sets > 1` (e.g. `185×8 ×3`): the row counts once, reps = 8 → "up". Test in Task 1.
2. Exercise with exactly one previous session (no deltas): jump falls back to 5 (upper) / 10 (lower). Test in Task 1.
3. Custom (non-library) lower-body exercise: lower-body detection must go through the merged library, not `EXERCISES`. Test in Task 1 with a `Library` containing a custom quads exercise.
4. Two PRs in one workout: the second row beats the first → both badged; header Best shows the second. Test in Task 1 (`isPr` with `before` including earlier same-workout rows).
5. Ties: logging exactly the best weight and reps again is **not** a PR. Test in Task 1.

  ```ts
  export type Suggestion = { weight: number; kind: "up" | "stay" | "build"; lastWeight: number; lastReps: number };

  export function beats(a: LiftRow, b: LiftRow): boolean;           // a beats b
  export function isPr(row: LiftRow, before: LiftRow[]): boolean;

  export function suggestNext(exercise: string, previousRows: LiftRow[], lib?: Library): Suggestion | null;
  export function suggestionLabel(s: Suggestion): string;
  ```
  `rows`/`previousRows` may contain other exercises; functions filter by `normalizeName`.

### Task 2: SetSheet — Best line, suggestion chip, PR pills

**Files:**
- Modify: `components/SetSheet.tsx`
- Modify: `app/workout/[id]/page.tsx` (openSheet seed + SetSheet props)

**Interfaces:**
- Consumes: `bestByWeight`, `isPr`, `suggestNext`, `suggestionLabel`, `type Suggestion` from `lib/progression.ts` (Task 1).
- Produces: `SetSheet` gains props `best: LiftRow | null` (all-time best over previous workouts ∪ rows logged this workout for this exercise) and `suggestion: Suggestion | null`, and a new prop `history: LiftRow[]` (all rows for this exercise from previous workouts, any order) used for per-row `isPr`.

- [ ] **Step 1: Workout page wiring.** In `app/workout/[id]/page.tsx`:
  - Add `const openRows = useMemo(() => open ? previousRows.filter((r) => normalizeName(r.exercise) === normalizeName(open)) : [], [open, previousRows]);`
  - `const openLogged = logged.filter((r) => normalizeName(r.exercise) === normalizeName(open))` (already computed inline for the `logged` prop; hoist to a `useMemo`).
  - `const openSuggestion = useMemo(() => open ? suggestNext(open, previousRows, library) : null, [open, previousRows, library]);`
  - `const openBest = useMemo(() => bestByWeight([...openRows, ...openLogged]), [openRows, openLogged]);`
  - In `openSheet(name)`: after computing `seed` from `prev[0]`, if `suggestNext(name, previousRows, library)` is non-null, set `seed.weight = snap(suggestion.weight, WEIGHT)`. Keep sets/reps seeding as today. When `prev` is empty and suggestion null → `DEFAULT_STATE` as today.
  - Pass `history={openRows} best={openBest} suggestion={openSuggestion}` to `<SetSheet>`.

- [ ] **Step 2: SetSheet header.** Under the existing `Last:` paragraph add:
  ```tsx
  {best && <p className="text-sm text-muted">Best: <span className="font-semibold text-accent">{best.weight}×{best.reps}</span> · {shortDate(best.logged_at)}</p>}
  ```
  "First time" stays only when `previous.length === 0 && !best`.

- [ ] **Step 3: Suggestion chip.** Between the header block and the wheels, when `suggestion`:
  ```tsx
  <button type="button" onClick={() => onState({ ...state, weight: suggestion.weight })}
    aria-pressed={state.weight === suggestion.weight}
    className={`mt-3 self-start rounded-full px-3 py-1 text-[13px] font-semibold ${
      state.weight === suggestion.weight ? "bg-accent/20 text-accent" : "border border-border text-muted active:text-foreground"}`}>
    {suggestionLabel(suggestion)}
  </button>
  ```
  (Wrap the wheels block's parent in a flex column if needed so `self-start` applies.)

- [ ] **Step 4: PR pill on logged rows.** In the `logged.map((r, i) => …)` list, compute `const pr = isPr(r, [...history, ...logged.slice(0, i)]);` and after the `{r.weight} × {r.reps}` span render
  ```tsx
  {pr && <span className="rounded-full bg-accent/15 px-2 py-0.5 text-[11px] font-semibold text-accent">PR</span>}
  ```
